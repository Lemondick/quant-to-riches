## 3. 本次发现并修复的账本问题

成交冲正曾以成本价重算市值；卖出冲正还曾将卖出价格和费用加入持仓成本。
这会在份额与现金恢复后，错误改变持仓收益口径。

修复后：

- 新成交的审计记录保留成交前持仓和原始成本。
- 卖出冲正按原始成本恢复份额成本，不把卖出价当成本。
- 冲正保留现有单位市值；已全部卖出没有剩余报价时使用该笔已记录成交价。
- 旧卖出记录没有原始成本证据时拒绝推算，返回中文原因，账户不变。
- 冲正与现金更新仍为原子操作，重复提交不会重复增加份额/现金。

本次验证仅写入独立临时数据库，没有对实际账户执行交易、冲正或费用确认。
