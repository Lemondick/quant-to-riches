## 归因计算与来源边界

固定持仓模式保持原价格收益逻辑；新增账本模式按事件日期划分最多60个期间，计入成交价相对期末收盘价的差额、实际费用及现金分红。已确认外部存取款按期末流量中和，不能称为精确的日内时间加权收益。期初无持仓标的的成交差额及分红归入现金贡献，页面和来源中明确说明。

每个边界均需要准确日期的已验证价格和当时已知行业。原始基线、审计或价格缺失、资金不足、涉及公司行动/冲正/持仓覆盖时阻止生成；基金行业穿透和官方指数历史成分仍不在本轮支持范围。冻结账本证据上限4MB，每期保留自己的期初持仓、贡献和审计引用；完整证据只在父报告保存一次，子报告关联父来源。账本分期和多期报告不能被单期重算覆盖。

实际隔离样例：初始股票200、现金800，期间卖出10股、手续费1，随后分红净额8、外部存入200。两期投资收益分别19和18；期末资产1237，外部存款没有混入投资收益。组合连结收益3.7%，基准20%，超额收益-16.3%。已验证API读取、保存来源和页面连结计算一致。

报告日期筛选采用整个报告区间位于筛选范围内的语义。CSV保留原始小数比例并防止电子表格公式注入；多期CSV仅输出累计行业效应，不虚构统一期初权重。JSON保留全部冻结来源及分期输入。越权下载返回404。

## 真实AI和费用结果

通过原项目已有连接生成一次真实晨报，新闻、策略、复核使用目录中的`gemini-3-flash`，Jev使用`jev-latest`；之后恢复用户原角色选择。四次调用均完成，阶段均为`response`，三个文本角色和Jev答案已保存，没有遗留费用预留状态；总输入20690、输出9235 tokens。

报告最终为`blocked`，无传输或输出错误。冻结原因是：指数行情不是当前交易时段数据、历史行情及来源证据未通过AI复核准入、没有本地筛选合格的候选。系统按规则保存研究报告，决策列表为空、`research_only=true`、`strategy_validated=false`。这证明四角色调用与记录闭环，不能证明策略通过投资准入。

四条实际调用都有角色、提供方、用量和阶段证据，费用为`null`、原因为`missing_price`。没有获得该兼容API/Jev实际单价及币种，不能拿其他服务商报价代入，也不能宣称免费或与真实账单对账通过。已知单价快照、精确核算、缺失用量、传输失败、中断及金额预算阻止无可靠上限请求的行为由隔离回归验证。
