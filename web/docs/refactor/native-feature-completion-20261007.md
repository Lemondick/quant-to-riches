## 已补通

| 功能 | 之前 | 当前行为 |
| --- | --- | --- |
| Jev 模型目录 | 页面只能保存 Key，判断模型只能手填 | `POST /api/v1/advisor/jev-models/discover` 使用固定官方 HTTPS 地址和账号 Key，支持留空沿用已存 Key。解析官方 `models[].name`，成功后保存目录，可选择别名，也保留固定版本输入。 |
| Brinson 归因 | 页面创建草稿后无条件报“尚未实现” | 填写行业汇总数据，前端先校验再提交。`POST /api/v1/attribution/reports` 携带 `details` 时一次事务完成创建和计算；原先创建草稿及单独计算的接口仍可使用。页面显示各效应、行业明细及报告 ID，可重新读取。 |

模型目录读取有公开地址校验、TLS 验证、禁重定向、连接切换和总超时。网络请求不持有数据库锁；保存前再次核对版本和运行中任务。坏 Key 或旧响应不会覆盖新连接；公开结果仅返回目录和 `has_key`，不返回密钥引用。切换账号时页面立即清理输入和结果，迟到的响应被忽略。

归因使用单期 Brinson–Fachler。页面填写百分数，API 发送精确十进制比例文本；组合与基准权重各合计 1。日期必须有效且开始不晚于结束，行业不可重复，收益率字段必须提供。行业明细和汇总在同一事务保存，重算会删除旧行业；写入失败整体回滚。读取也使用一致的数据库快照；跨账号读取或计算返回 404。

所有现有归因报告来源均为 `manual_sector_input`，页面明确显示“手工录入”，不会将它描述为自动取得的持仓或基准事实。
