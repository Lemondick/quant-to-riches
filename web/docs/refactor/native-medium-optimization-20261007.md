# 中级问题优化与隔离验收

日期：2026-10-07。继续直接实施中级问题修复，部署仍采用单服务器原生运行方式。验收只使用本机隔离库及合成账户，没有正式切换或提交交易。

本轮范围为资金计划分页与筛选、截图批量失败恢复、账户切换隔离，以及验收中发现的持有导航故障。成功标准是全部计划可访问、失败可恢复且不重复写入、旧账户数据及时清除、实际页面与最终发布包一致。

## 已完成

### 资金计划分页与筛选

- API 增加 `offset`、`limit`、`total` 和 `has_more`，保留原有 `items`。每次最多500条，按起始日期及计划编号稳定排列；状态筛选、总数与分页采用同一账户条件和同一数据库读取快照。
- 页面每页20条，提供全部、生效、暂停、已完成筛选和上一页、下一页；切换筛选回到第一页，末页禁用下一页。编辑或状态变更后刷新当前页，空末页自动回退；新建后刷新第一页。
- 服务端已确认保存但列表刷新失败时，显示“计划已保存，但列表刷新失败”，清空创建表单，避免把刷新失败当成写入失败而再次创建。
- 金额继续以精确十进制文本传输；修复原生金额和日期输入框的深色样式。切换账户立即清除列表、筛选、草稿和日期查询结果，迟到响应不能恢复旧数据。

### 截图批量失败恢复

- 每张图片显示等待、识别中、成功或失败状态；单张失败后继续识别后续图片，整批成功前不能进入确认导入。
- 用户可明确重试失败图片，复用当前账户中仍有效的成功预览；合并请求失败时可只重试合并，减少重复OCR调用。
- 服务端预览有效期15分钟，客户端只复用14分钟内的结果，留出合并和核对时间；过期预览重新识别。
- 账户切换同步清除图片批次、持仓草稿、现金、差异、确认状态及错误。所有异步阶段校验账户及操作版本，旧请求的返回、异常和结束处理不能改写新操作。
- 保持原有人工核对和明确确认流程，不自动保存持仓。

### 子页面导航

持仓明细和导入页共用“持有”导航高亮，原实现因此误认为已经在首页而忽略点击。现在依据实际页面路由判断：子页面点击或按Enter可回到首页，在首页点击则保持当前页面。
