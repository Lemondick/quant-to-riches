# 原生版功能补全计划（2026-10-07）

按当前代码及已迁移流程检查，继续直接实现和验证；保持单机、无 Docker，不改既有账本或交易行为。

## 本轮范围与验收

1. **Jev 可用模型目录**：固定官方 HTTPS 地址，通过账号自己的 Key 读取 `/v1/models`，兼容官方 `models[].name` 格式。成功后保存加密连接及目录；失败不覆盖原配置。前端可沿用已存 Key、选择别名，仍支持填写官方固定版本。请求期间不持有数据库锁；沿用超时、公开地址校验和禁止重定向。校验账号隔离、版本冲突、坏 Key、延迟响应及敏感信息清理。
2. **Brinson 归因报告**：当前页面创建草稿后无条件报未实现。先接通行业数据录入 → 校验 → 计算 → 保存 → 重新读取；完整数据一次事务写入，重算替换旧明细，禁止空数据、重复行业、不完整权重和无效日期。页面输入使用百分数，API 使用比例。验证效应之和等于超额收益、失败不污染旧报告、跨账号不可读取或修改。

## 明确的数据边界

Jev 官方模型目录只验证目录权限，不保证报告调用权限。官方目录提供别名，固定版本可能不在目录内，因此保留版本输入。格式依据：https://docs.typesafe.ai/models。

Brinson 自动聚合尚缺期初历史持仓、同日期基准行业权重及行业收益的可靠数据源。不能用今天的持仓回填历史，也不能把指数整体收益复制到每个行业。本轮使用用户提供的真实行业汇总数据，并明确显示来源为手工录入；自动聚合仍为待办。
