## 实际发布版联动

通过 `publish.ps1` 构建完整原生发布包，使用新空库执行十二组实际 HTTP 场景：

1. 管理者登录、Secure Cookie、匿名保护、数据库及三个 worker 就绪。
2. 开放注册、创建两个普通账号、关闭注册及读取用户列表。
3. 首次保存自选、幂等回读、资讯已读、CSRF 拒绝及账户隔离。
4. 买入、卖出、分红、冲正及拆分；重复外部编号不重复入账，他人无法读取交易。
5. 定投计划与计算。
6. 月末现金流计划日期及精确预算、模型单价。
7. 人工费率证据及赎回费用报价。
8. 因子记录、宏观证据及自定义基准的保存与隔离。
9. 回撤验证及重复确认。
10. 管理者持仓、账本、自选、报告、研究任务、统计、时间线及导出。
11. 真实 worker 领取并完成数据状态、收益归因、生命周期、策略设置四类计算。
12. 研究预览资格拒绝、停用后会话失效、重新启用后登录。

十二组全部通过。交易组合从合成现金 10,000 开始，最终现金 8,994，基金份额 200、平均成本 5.275；冲正后的历史卖出仍可追溯。管理者页面与普通用户持仓、账本展示这些一致数据。
