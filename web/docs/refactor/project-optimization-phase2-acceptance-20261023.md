# 第二轮项目优化验收记录 — 2026-10-23

本轮落实用户“继续优化”的前两项优先工作：资产统计范围与可恢复后台计算。沿用现有 Vue、ASP.NET Core、compute_jobs 和 Worker 租约，无新依赖、数据库迁移或真实账本写入。原同步接口及旧客户端数字字段保持兼容。

## 已实现行为

- 本币折算按代码和资产类型匹配币种，只累计已知币种且有有效汇率的非现金持仓；未知币种按数量展示，缺汇率明确排除。原金额与折算值各用对应币种单位，隐藏金额同时遮蔽相关卡片。
- 人民币汇总及仓位仅在持仓和现金币种均确认 CNY 时显示；非零现金缺少币种记录时也不合并。完整跨币种账本尚未实现。
- 净资产响应增加 `liabilities_recorded:false` 和 `calculation_scope:positions_only`。连接页面将负债显示为“未登记”、净资产为“未计算”；原币账本记录、历史和比例明确标注未折算。
- 组合回测、估值、智能定投回测可通过 `background=true` 创建后台任务；GET/DELETE `/api/v1/compute/tasks/{id}` 仅查询或取消当前账户允许的三类任务，响应不含输入、租约凭据或 Worker 信息。
- 组合回测、估值页、首页估值卡片已接入状态查询。只在当前标签页按用户和会话保存任务编号，刷新或返回页面可恢复，跨账户迟到响应不会显示。
- 查询失败通过“继续查询”恢复，不重复创建。估值成功后在可见页面每分钟重新查询；更新期间保留旧结果，有活动任务不重复提交。失败、中断、取消及首次请求失败后首页可明确重算，取消不会触发自动重启。
