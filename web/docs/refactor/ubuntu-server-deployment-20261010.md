API 日志在 `/var/log/quant`，限制滚动大小与保留数量。日常备份维护窗口为北京时间 02、03、04 点，随机延迟最多一分钟；8 小时内成功备份则跳过。有排队/运行任务或费用预留时本次退出，下一窗口重试。归档会短暂停服，恢复完成后检查 readyz。

普通站点归档位于 `/var/lib/quant/backups`；包含私密恢复材料的额外归档位于 `/var/lib/quant/private-backups`，目录 0700、文件 0600、root 所有。两者保留 14 份。私密归档包含配置、证书私钥、模型解密材料，应按秘密保管。当前仅保存在同一服务器，没有配置加密异地副本。

手动强制备份：

```bash
sudo /opt/quant/current/backend/.venv/bin/python /usr/local/lib/quant/backup-linux.py --force
```

网关配置回退文件在 `/home/ubuntu/guanlan-deploy-evidence/Caddyfile.before-20261010`。现有 Caddyfile 是 Docker 单文件绑定，回退须原位写入并 reload，保留文件 inode：

```bash
sudo bash -c 'cat /home/ubuntu/guanlan-deploy-evidence/Caddyfile.before-20261010 > /home/ubuntu/caddy/Caddyfile'
sudo docker exec caddy caddy validate --config /etc/caddy/Caddyfile --adapter caddyfile
sudo docker exec caddy caddy reload --config /etc/caddy/Caddyfile --adapter caddyfile
```

这只恢复旧网关入口，不会删除新站点或更改其他应用数据库。升级、数据库回退和新库恢复须遵守[Ubuntu 部署说明](../../backend-dotnet/deploy/ubuntu-runbook.md)，不能将演练库直接替换为正式库。
