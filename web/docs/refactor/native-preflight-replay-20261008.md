# 本机隔离优化验收记录（2026-10-08）

本轮完成免费 AI 预检、基金执行回放与归档导出、自动验收覆盖三项优化。沿用 C# 原生 API 与 Python worker，在本机隔离环境验收；没有正式切换，没有使用 Docker，也没有安排长期后台运行。

## 已实现的行为

### 生成报告前免费检查

早报和基金报告入口先检查模型配置、额度、预算及研究资料。缺项展示原因和对应页面入口，用户明确点击生成后才进入模型调用。预检复用生成报告的证据规则，不调用模型、不占报告额度，不传递模型密钥。

新增 `POST /api/v1/advisor/preflight`。结果有效期为两分钟，只用于提示；实际生成仍重新检查当前配置和预算、冻结当前资料。启用金额预算而连接无法提供可靠成本上限时，服务端在创建报告前拒绝生成。切换账户、离开页面或刷新会清除旧预检，迟到的响应不能覆盖新账户状态。

### 基金执行回放、归档和导出

基金复盘页可下载待补全的证据模板，上传经核对的 JSON，按净值公布、申赎确认及资金到账时间执行回放。模板默认未核对，不含假定的真实费率或交易日历。

新增 `/api/v1/research/funds/execution-replays` 下的创建、列表、读取、导出和删除接口。输入限制为 2 MB、最多 1,000 笔订单，并校验字段、时间及证据。每个账户最多保存 20 份归档；归档冻结输入和结果，通过 SHA-256 指纹核对后读取或导出。其他账户不能读取、导出或删除。

未结清持仓、待到账资金或拒单不输出净收益；未核对的证据、未来信息及不支持的分红拆分等情形会阻止完整收益结论。页面修复了未上传资料时按钮的禁用状态，并按北京时间显示归档时间。

本功能用于研究回放，不自动取得策略准入、实盘交易或纸面运行天数资格。AI 报告与真实交易的逐笔关联尚未实现；回放结果不能视为实际账户业绩。

### 自动回归

CI 补入此前遗漏的优化检查脚本，并新增构建后 H5 的 Chromium 回归。浏览器覆盖免费预检、修复入口、预算变更、明确生成、回放上传和导出、账户切换后的迟到响应，以及未配置模型等七个场景。浏览器边界服务使用合成响应，阻断外部请求。

远端 CI 尚未执行；本轮执行并通过的是本机对应检查及最终发布包验收。
