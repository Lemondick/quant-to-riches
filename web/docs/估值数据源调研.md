# 指数 PE/PB 历史数据源调研（batch4 任务 #5，2026-10-21）

> 背景：估值仪表盘（`valuation.percentiles`）的 PE/PB 历史百分位需要每个指数
> ≥60 个历史观测点的 PE/PB 序列。当前无免费公开源，`ValuationSource`
> 默认未接线（`web/worker/valuation_operations.py`），返回空 items + warning，
> 不虚构数据。本次调研结论：**无合规免费源，本次不实现抓取 op**。

## 调研方法

- 公开资料检索（2026-10-21）：各候选源的公开页面、数据产品说明、法律声明/免责声明；
- 合规判定标准（按 batch4 契约"合规优先，不确定的源宁可不用"）：
  1. 是否有**文档化的公开 API** 或明确允许程序化访问的条款；
  2. 数据是否为该机构的**商业授权产品**（抓取会绕过其授权体系）；
  3. 数据维度是否满足需求（PE 与 PB 双序列、历史 ≥60 观测）。

## 候选源逐项结论

### 1. 中证指数官网（csindex.com.cn）—— ❌ 不可用（合规）

- 数据情况：网站"指数估值"频道与各指数详情页展示滚动市盈率、市净率等基本面指标；页面由内部 JSON 接口驱动（含历史估值走势）。akshare 的 `stock_zh_index_value_csindex` 调用的就是同类内部接口，技术上可取到历史序列。
- 合规问题：
  - 无文档化公开 API，无允许程序化抓取的条款；
  - 中证指数的数据是**商业授权产品**：指数基金招募说明书披露须向"中证指数有限公司"支付指数许可使用费（年费率约 0.016%，每季度下限 5 万元）。系统性抓取其内部估值接口等同于绕过其数据授权体系；
  - 其公开文件的免责声明仅覆盖投资建议，不构成抓取授权。
- 结论：数据维度满足，但合规不满足。**不用**。

### 2. 东方财富（data.eastmoney.com/gzfx 估值分析）—— ❌ 不可用（合规）

- 数据情况："估值分析"数据中心有市场估值概况（日频历史平均市盈率）与行业估值详情，同样由页面内部 JSON 接口驱动。
- 合规问题：无公开 API 文档；东财网站页脚有"法律声明/版权所有：东方财富网"，其数据产品（Choice 金融终端）为收费商业产品；内部接口为页面渲染服务，未授权第三方程序化调用。按"不确定宁可不用"原则**不用**。

### 3. 同花顺（10jqka）—— ❌ 不可用（合规+反爬）

- 数据情况：有行业历史 PE/PB 走势图等估值内容。
- 合规问题：无公开 API；页面有明确反爬机制。**不用**。

### 4. 新浪 / 腾讯行情接口 —— ❌ 不可用（数据维度）

- 指数行情快照仅含**当前**市盈率等字段，无历史序列，无法计算历史百分位（需求 ≥60 观测）。
- 合规上同样属于未文档化的内部接口。

### 5. akshare `stock_zh_index_value_csindex` —— ❌ 不可用（合规）

- 技术上是对源 1 内部接口的封装，合规问题与源 1 相同（抓取中证指数内部接口）；
- 另：akshare 社区文档自身提示目标站点有反爬与封 IP 风险，不适合作为无人值守的定时抓取依赖。

### 6. Tushare Pro —— ❌ 不满足"免费"（备选付费/半付费通道）

- 合规面是候选源中最好的：文档化 API + 用户协议，是正规数据服务。
- 但：需要注册 token，免费积分有限（指数类多为高积分接口）；经检索未确认其提供宽基指数（沪深300/中证500 等）PE/PB **历史**序列的免费接口（`index_daily` 仅 OHLC）。
- 结论：不作为免费源实现；列为备选（用户自购额度后可接入）。

### 7. 上交所 / 深交所官网市场统计 —— ❌ 不可用（数据维度+合规）

- 上交所发布 A 股整体市盈率等市场总貌统计，深交所有类似市场数据，多为浏览页/Excel 下载，无指数层面 PE/PB 历史序列的程序化授权接口。
- akshare `stock_a_pe`（含 000300.XSHG 等指数市盈率）本质是抓取交易所页面，同属灰色地带。

## 总结论

| 维度 | 结论 |
| --- | --- |
| 合规免费源 | **无**。数据维度满足的源（中证指数、东财）均为商业授权/未授权内部接口；合规的源（Tushare Pro）不免费且未确认有指数估值历史接口 |
| 本次实现 | **不实现** `valuation.pe_history` 抓取 op；`ValuationSource` 保持未接线，仪表盘继续返回空 items + warning（不虚构数据） |
| 代码改动 | 无（仅本文档） |

## 备选方案（需用户决策后另行立项）

1. **用户自助录入 CSV（推荐，零成本）**：每月/每周从中证指数官网人工抄录各指数当前 PE/PB（浏览页面是允许的个人使用），按固定格式导入。需实现：CSV 导入 op + 本地历史表（新迁移 0043+，`valuation_history(symbol, day, pe, pb)`）+ `ValuationSource` 的 CSV/DB 实现。数据为用户手工录入的真实值，不违反"不虚构"原则。
2. **付费数据源**：Wind / 东方财富 Choice / Tushare Pro（用户自购），实现对应 `ValuationSource` 适配器接入已有可插拔点（`valuation_operations.py` 的 `ValuationSource` Protocol 无需改接口）。
3. **中证指数官方数据授权**：若未来中证指数开放合规 API/授权下载，优先接入（数据源最权威，与仪表盘口径一致）。
