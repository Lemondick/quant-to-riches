# 量化宝网页版使用手册

## 2026-10-05新增操作

账本新增“平台与主账本对账”：先保存各平台完整快照，选择要合并比较的账户，并确认这些账户覆盖主账本。页面显示份额、成本、市值及指定日期区间的费用差异；快照日期、成本或平台费用证据不足时保留待核对状态。可保存解释或待跟进说明，对账本身不会改变现金和持仓。

账本新增“历史成交补录与回算”：填写真实成交日期时间、份额、价格、费用、唯一外部编号及核对依据，先查看持仓、现金和全部已保存净值的前后变化。点击确认后还需确认对话框。预览有效15分钟；改表单、切换账户、账本变化或估值证据失效后须重新预览。确认追加成交和修订审计，原始成交及报告保留；重复确认不会再次入账。缺完整基线、正式估值或事件顺序证据时阻止回算。转托管、同日校准混合其他活动、影响后续公司行动权益的补录须单独核对。

“设置 → 模型成本”可填写每个模型每百万输入/输出token的实际单价、币种和每日金额预算。费用依据服务商返回的用量计算；缺用量或单价显示未知。当前连接没有可验证的调用前token上限，启用金额预算将阻止新的付费调用；已有次数和并发限制仍生效。

“设置 → 提醒中心”可调整数据过期天数、账户回撤阈值和任务失败观察范围，查看并确认提醒。同一风险去重；数据或净值证据不足时显示未知，确认提醒不表示风险已解决。

“设置 → 当前账号”可查看有效登录会话并撤销指定设备或其他设备。忘记密码时由管理员在用户详情签发15分钟、一次性恢复码，再在登录页使用“恢复密码”；密码恢复后所有旧会话失效。

管理员后台新增用户使用时间线和30天每日操作趋势，统计真实业务及账号事件，轮询读取不会增加操作次数。“运行状态与完整备份”显示各账户任务、失败、全站模型并发、业务库状态及备份校验结果。敏感查看、导出和恢复码签发均记入管理员审计。

首页“开始使用”按已保存状态提示建立持仓与现金、确认首个有效净值基线、配置个人模型、生成首份报告。证据与配置不全时保持原准入门槛，不自动调用模型。

账本下方“完整历史记录”切换交易与分红、公司行动、冲正，按代码和开始/结束日期查询、分页浏览全部结果。日期含首尾日，按北京时间核对。“导出筛选结果”生成CSV，单次最多10万条；“最近交易概览”是最近记录预览。

基金用六位代码 `000001`；股票可用六位或完整代码 `000001.SZ`，后台对股票补交易所后缀，股票与基金不共用持仓标识。截图成交批量确认时，任意一条失败撤销整批交易、持仓、现金与审计写入；重复提交相同外部编号不会重复记账。

首页与自选超过20只基金时分批读取，失败批次不清空其他成功结果。估值不能代替正式净值，缺失不补造。

版本日期：2026-10-04。普通使用者主要操作网页；仅首次安装、启动和故障维护需要命令行。
完整功能与数据口径见[功能说明](功能说明.md)。

## 1. 启动与进入系统

在项目根目录`C:\Users\admin\Desktop\量化\量化`打开PowerShell：

```powershell
.\启动网页版.ps1
```

首次运行按终端提示设置管理者用户名和密码，然后等待`status: ready`并打开 <http://127.0.0.1:8765> 登录。
启动器构建网页并准备后台服务。登录和注册方式见[登录与用户管理](登录与用户管理.md)。
需要安装依赖或遇到执行策略/端口问题时，按[维护说明](维护说明.md)处理。

已有构建时可更快启动：

```powershell
.\启动网页版.ps1 -SkipBuild
```

修改代码后应运行不带`-SkipBuild`的启动命令。不要通过删除`data/`来“重置页面”。

## 2. 第一次使用的顺序

1. 打开“设置”，检查后端连接和健康状态。
2. 在“自选”添加自己关注的基金，确认6位代码与A/C份额。
3. 进入基金详情，查看净值日期、申赎规则、公告和公开费率。
4. 需要管理真实持仓时，从首页进入“截图导入基金”，识别后核对并保存。
5. 需要完整收益账本时，核对完整账户与现金基线，再预览并确认净值入账。
6. 在基金详情登记实际支付宝费率和全部剩余持有批次。
7. 在“设置→AI模型配置”读取可用模型，选择角色模型并保存。
8. 浏览“基金复核”“AI选股”“策略”，按报告提示逐项补齐必要证据。

暂时不提供真实截图，也能看自选、行情、基金详情、资讯和公开净值研究。
这些功能可用，不代表真实账户的买卖决策准入已经通过。

## 3. 登录和账号

使用网站账号密码登录；新用户在登录页选择注册，总人数最多30人，管理者计入上限。每个账号独立保存持仓、账本、模型配置和报告。

在设置页检查服务连接、修改密码或退出。管理者进入“管理者后台”，在用户行选择“查看详情”，可只读查看该用户的持仓、成本、市值、浮动盈亏、账本、自选、报告正文和研究任务。会话最多12小时，失效后重新登录；网页无需填写共享访问Token。模型API Key只用于当前账号的模型服务。

## 4. 添加基金与查看行情

在“自选”搜索6位代码或名称，核对资产类型后点击星标加入。
没有已有匹配时，选择基金/股票/指数，填写可选名称并添加。
同一代码可能对应不同资产类型，确认名称和类型后再保存。

首页与自选中的基金可进入详情；在“行情”切换指数、基金榜、板块。
搜索、分类、展开和收起直接处理已读取的列表。
首次读取等待时会显示加载状态；已有缓存时先看旧值并保留原日期，后台再更新。

| 页面提示 | 应如何理解 |
| --- | --- |
| 净值 | 正式净值，有独立的净值日期 |
| 上次行情/缓存行情 | 已保存的旧数据，本次更新未必成功 |
| 读取中/更新中 | 请求尚未完成，不等于数据已验证 |
| 未更新/行情暂不可用 | 当前没有合格报价，不能把空白当作零涨跌 |
| 部分更新 | 部分来源完成，其他分区仍缺失或失败 |

周末、节假日看到上一个披露日的正式净值通常不意味着页面坏了，需核对净值日和来源状态。
盘中估值与正式净值分开看，不用估值替代正式净值入账。

## 5. 上传支付宝持仓截图

从首页点击“截图导入基金”：

1. 点击“上传截图并识别”，选择不超过6张清晰图片。
2. 图片应保留基金名称、A/C份额、份额、市值/成本和日期等相关区域。
3. 等待识别完成，逐项检查基金代码、名称、持有份额、成本和市值。
4. 名称匹配给出多个候选时，选择准确代码；不要把A类持仓确认成C类。
5. 对识别错位、缺失或冲突的字段手动修改，再重新核对。
6. 查看本次导入将产生的变化及日期，确认后保存。
7. 回到持有页刷新，检查导入状态及持仓是否与平台一致。

支持PNG、JPEG、WebP，单张不超过6MiB。过大、模糊或裁切过度的图片需要重新准备。
图片会发往外部OCR服务，不要包含与基金核对无关的身份证、付款码等内容。

系统可按准确份额和公开正式净值估算市值，但这与截图时点的实际市值可能不同。
净值日与截图核对日期不能混为一谈。
个人成本、真实现金及历史订单批次需从本人账户核对；公开接口无法自动取得。

截图持仓导入不一定建立完整账本基线。页面显示“尚未确认账户/净值基线”时，
按提示补齐完整账户、现金和日期后确认，不反复上传同一截图尝试消除阻断。

## 6. 手动录入与完整账户基线

截图不可用时，可展开“手动录入或修改截图日期”，选择“手动录入完整账户”。
逐项填写基金代码、份额、成本、市值等必填信息，并核对账户现金和日期。
检查总资产、记录变化及相关提示，明确确认后保存。

完整账户应包含核对时点的全部相关持仓和实际现金；单只基金截图不能代表整个账户。
不要用估算现金或合成成本建立用于真实交易的账户基线。
完整账户快照保存后，还需在账本中预览并确认该日期的正式净值入账。
在首条正式净值入账之前，系统会阻止后续成交录入；按“净值基线待入账”提示完成此步骤。

## 7. 基金日K、周K、月K、年K

进入基金详情，在净值分区切换曲线/K线及单位/累计净值序列。
在“净值K线”点击日K、周K、月K、年K。
鼠标移到图上或聚焦图表后使用左右方向键查看日期与观测；Home/End跳到首末记录。

日K的开、高、低、收均为当日正式净值；周/月/年K是正式净值记录的聚合。
图中没有基金当日分时成交信息。缺少净值的周期只聚合已有观测，并显示缺口。
区间净值变动不等于本人扣费后的实际收益。

## 8. 登记支付宝实际费率

基金详情进入“实际费用”，点“登记或更新实际费率”：

1. 核对基金代码及A/C份额。
2. 填写实际申购费率；使用金额分档或固定收费时，登记完整分档。
3. 填写销售服务年费率，以及按持有天数划分的赎回费率。
4. 填写核对日期、生效日期和平台页面/公告/确认单等核对依据。
5. 勾选本人已核对的确认项，检查分档完整性，再保存。
6. 保存后重新读取，确认页面显示当前有效的记录。

页面百分比字段按标签填写，例如`0.1`表示`0.1%`，不要将后台小数口径直接粘贴到百分比字段。
金额分档的区间边界需连续且无重叠，不能只填写自己当前金额附近的一档。
以平台当时对该基金和本人交易适用的费率为准，公开详情页不能自动证明实际申购折扣。
记录过期、尚未生效或读取失败时，需要重新核对；勾选确认并不能替代实际收费证据。

## 9. 核对剩余批次与试算赎回费用

基金详情进入“持有批次”：

1. 根据平台确认单，逐批登记编号、买入确认日及剩余份额。
2. 只登记当前剩余份额；已全部赎回的批次不再当作剩余持仓。
3. 检查所有批次剩余份额合计是否等于当前已确认持仓。
4. 填写核对日期、依据，确认已核对全部剩余批次后保存。
5. 试算时，按照平台实际对应批次填写各批次本次拟赎回份额。
6. 填写预计确认日与规划净值，点击“计算选定份额费用”。
7. 查看每批持有天数、费用及估计净额，再自行核对平台确认信息。

系统不自动决定平台的批次扣减顺序，不提交赎回。持仓发生变化后，应重新核对批次。
份额超出余额、批次不一致或费用证据缺失时，按具体提示修改，不能通过重复点击绕过。

## 10. 维护账本与正式净值

从持有页进入“账本”，按实际已确认记录操作：

1. 补录成交时，填写基金/股票代码、买卖方向、确认日期、价格、份额及实际费用。
2. 分红登记现金分红或红利再投，核对份额与现金变化。
3. 外部入金/出金独立登记；不要把入金误记成投资收益。
4. 完整账户基线尚未确认时，先完成基线；缺少现金或持仓时不要随意补零。
5. 每次提交后核对账本及持仓变化。提交超时先刷新记录，确认是否成功，避免重复录入。

“正式净值入账”先选日期并生成预览，检查基金净值、账户现金、数据缺口及合计，再明确确认。
预览过期或持仓已变化时重新生成，不能确认旧预览。
发现错录记录时使用冲正/更正入口并写明原因，保留原始记录和修改依据。
旧卖出记录未保存成交前成本时，系统会拒绝推算成本进行冲正；按提示使用完整账户对账校准。
冲正日期不能早于原记录或当前账本日期。买入后已有卖出时，先核对并处理关联卖出；
原成交后已有拆分、基金转换或完整账户校准时，使用完整账户对账校准，不能直接套用原份额进行冲正。
这些操作维护本地账本，不会向支付宝或券商提交订单。

## 11. 配置模型并发现可用列表

进入设置中的模型区域：

1. 在连接表单登记兼容接口地址和自己的 API Key，连接参数由后端保存。
2. 点击获取/刷新可用模型，等待接口返回该 Key 有权限使用的模型列表。
3. 为资讯整理、策略草案、风险复核分别选择模型。
4. 在“Jev 官方 API Key”保存自己的独立官方Key，核对决策模型ID；普通兼容接口的列表不能证明Jev可用。
5. 保存角色选择，再重新读取，确认保存结果。

密钥仅保存在当前账号的服务端私有目录，保存后不明文回显。
获取模型列表不生成 AI 分析报告；真正创建报告会调用模型并可能计费。
若接口不支持模型列表、Key 权限不足或地址错误，按提示核对连接，不能凭空填出“可用”列表。
其他页面已修改设置时，当前保存可能提示版本冲突；先重新读取再修改。
每份已创建报告保留创建时的模型选择，之后改模型不改变旧报告。

## 12. 使用 AI 选股

1. 打开“AI选股”，先核对股票候选及数据日期。
2. 需要改变筛选条件时，编辑并保存策略参数，再运行筛选。
3. 查看候选分数、关键依据、风险和准入状态。
4. 发起 AI 研究前核对预览及模型配置；只提交一次。
5. 等待后台任务完成后查看报告；离开页面后可从报告列表再次进入。
6. 检查最终 Jev 判断与阻断原因，而不是只读策略模型的草案。

数据缺失、休市、模型分歧或准入未通过时，结果是观察/研究。
读取报告、刷新列表和切换页面不会自动等同于再次创建付费报告。
遇到超时先查看已有任务状态，不要立即重复创建。

## 13. 使用基金复核

打开“基金复核”，先检查持仓、自选基金、数据日期和最新报告。
缺少费用、剩余批次、申赎规则或回放证据时，展开阻断原因并按对应入口补齐。
真实持仓仍未核对时，可以查看公开基金资料和研究结果，但不能把观察结论当作完成交易准入。

报告流程依次包含资讯、策略、风险复核和 Jev 最终选项判断。
结合平台申赎状态、确认时间、实际费用、自己的现金与剩余批次核对结果。
买卖建议不会自动修改持仓，也不会在支付宝执行。

## 14. 策略对比、建议跟踪与组合风险

在“策略”中的基金投研模块：

1. 选择基金、样本区间和费用情景，比较买入持有、分期投入与月度趋势观察。
2. 查看扣费后收益、回撤、预算投入比例和总费用，结合资金/回撤曲线核对。
3. 更新公开研究时观察版本、数据截止日期和生成时间；失败后旧研究仍可查看。
4. 打开“建议跟踪”，查看原始判断及后续有效净值记录是否收齐。
5. 打开“组合风险”，核对当前组合的暴露、证据缺口和数据日期。

情景费率不是支付宝实际费率，情景收益不是自己的已成交收益。
样本外表现及后续跟踪尚未验证时，不能因为某条历史曲线赚钱就直接加仓。

## 15. 每天使用的建议顺序

| 时间/阶段 | 操作 |
| --- | --- |
| 启动后 | 看服务状态、数据日期及是否有未处理任务 |
| 09:30交易日 | 看系统生成的早间资讯和 AI 选股报告 |
| 14:30交易日 | 看基金复核结果，核对申赎、实际费用和批次 |
| 平台确认成交后 | 更新实际成交、现金与剩余批次 |
| 正式净值发布后 | 预览并确认净值入账，查看收益和建议跟踪 |
| 修改配置/版本前 | 停止服务后备份账户与私有配置 |

任务由后端系统定时执行，窗口分别为北京时间09:30–09:44、14:30–14:44。
后端需要持续运行；休市不生成任务和提醒，错过窗口不补发旧建议。
系统内通知可查看和确认，当前不发送微信。

## 16. 常见问题

| 现象 | 处理 |
| --- | --- |
| 首次没有行情 | 等待首次采集；检查服务和公开来源，失败时使用重试入口 |
| 有数值但标注缓存/旧日期 | 可查看旧值；核对正式日期后再用于当前判断 |
| 后端离线 | 运行启动脚本，检查端口和设置中的连接地址 |
| 401/登录已失效 | 重新登录当前网站账号 |
| 已连接但模型列表为空 | 核对模型接口地址、Key 权限和模型列表支持情况 |
| 模型返回不支持或权限不足 | 刷新列表并换成当前 Key 可用的模型，重新核对角色选择 |
| 任务一直显示进行中 | 检查后台状态与错误；不要重复点击创建付费任务 |
| 截图未识别出份额/成本 | 修改识别草稿或使用平台可显示这些字段的详情图；公开净值无法代替个人成本 |
| 基金K线缺少最近日期 | 正式净值尚未发布或来源读取失败；查看日期，不把估值混入正式K线 |
| 基线、费率或批次未通过 | 进入对应核对表单，补齐真实信息和依据 |
| 休市没有提醒 | 系统的预期行为 |
| 保存超时 | 先重新读取已保存数据，再决定是否重试 |
