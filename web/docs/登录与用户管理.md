# 登录与用户管理

## 2026-10-05新增管理能力

管理员详情增加按类别、日期分页的使用时间线及30天每日操作趋势，涵盖导入、成交、净值、报告、任务和账号维护；轮询请求不算实际操作。管理员读取明细、导出、报告、时间线和运行任务时记录操作者、目标账号、类别及查询范围，审计不复制财务正文、密码、恢复码或Key。

设置中的登录会话列表展示粗粒度浏览器/系统标签、创建与过期时间，可撤销单个会话或其他设备。管理员可在用户详情签发一次性密码恢复码；原码仅在签发时显示，不存浏览器缓存，数据库仅存哈希。15分钟后失效，签发新码使旧码失效，成功恢复密码后撤销全部旧会话。站点恢复会清空会话及恢复码，避免恢复备份后复活已使用凭据。

用户列表显示最近登录、最近活动、近7天请求与错误。详情页增加报告成功/失败数、平均任务耗时、每日使用分类和最近任务异常。活动统计从升级后开始采集，保留90天，记录时间、分类、次数、状态与耗时，不记录正文或Key；任务耗时含排队，失败包括阻断、取消和超时。最近活动不表示当前在线。

“停用”撤销全部会话，阻止后续登录、访问和新研究任务；“恢复”需要重新登录，不恢复旧Cookie，已排队的股票研究可能继续执行。“强制退出”撤销会话但允许重新登录。管理员不能在后台停用或强制退出自己，自己的账号在设置中管理。已发送的模型请求可能结束，后续日报阶段与研究取消检查会识别停用状态。

注册开关不会突破30人硬上限，停用不释放名额。账号状态、强制退出、注册开关和日历操作保留管理员、目标、内容、时间的分页审计。

持仓、账本、报告、任务按代码和日期筛选，自选按代码筛选。日期按北京时间包含首尾日：持仓按数据日，账本按发生日，报告/任务按创建日。CSV导出完整筛选结果，单次最多10万条，超过时缩小日期范围；不包含密码、模型连接与Key。

“站点管理 → 年度交易日历维护”填写年份、交易所官方HTTPS公告链接、逐行休市日期。周末自动休市，缺失/损坏的年度日历显示提示并暂停自动日报。管理员逐项核对官方全年公告后录入。

完整备份恢复见[维护说明](维护说明.md)。

网页使用账号密码登录。最多注册 30 个账号，管理者计入总数，没有注册截止时间。达到上限后已有账号仍可登录。

## 首次启动和管理者初始化

在仓库根目录运行：

```powershell
.\启动网页版.ps1
```

首次启动会在终端提示输入管理者用户名和密码。用户名为3至32位字母、数字或下划线，以字母开头；密码为15至128个字符。输入密码时不回显，没有默认密码。创建的管理者使用原有持仓、账本和模型配置，其他新用户从空账户开始。

也可以单独初始化，仓库根目录执行：

```powershell
web/backend/.venv/Scripts/python.exe -B -X utf8 web/backend/scripts/manage_users.py init-admin --data-dir data
```

管理者初始化完成前，网页不开放注册。公开注册永远只能创建普通用户。

## 用户注册和使用

登录页选择“还没有账号？注册”，填写用户名、密码和确认密码。注册页显示已注册人数和剩余名额，后端保证并发注册也不会超出30人。用户名忽略大小写并去除首尾空格，密码中的空格保留。

登录成功后进入个人工作台。持仓、账本、自选、模型连接、研究任务、报告和通知按账号隔离，个人模型Key在该用户服务端私有目录保存。网页登录通过当前网页服务完成，不需要手工填写共享Bearer Token。

新用户使用AI日报时，在“设置 → AI模型配置”保存自己的兼容API连接及独立Jev官方Key，选择角色模型并保存。配置随账号保存在服务端，重启后继续使用；站点运行的行情/OCR采集可共享服务连接，个人模型密钥不共享。

在设置页查看当前账号、修改密码或退出。登录会话最多12小时；退出立即撤销当前会话，修改密码撤销该账号所有原有会话。浏览器会在退出和切换账号时清理上一账号的缓存。

## 管理者后台

管理者登录后进入“设置 → 管理者后台”。后台显示注册人数、人数上限、剩余名额、启用账号数，以及按用户名筛选的用户列表：

- 用户名、管理者/用户角色和启用/停用状态。
- 注册时间与最近成功登录时间，按北京时间显示；最近登录不表示当前在线。
- 持仓数量：主账本和有效账户快照中，份额大于零的非现金标的去重数。
- 账本记录数量：交易和分红历史记录总数，包含已冲正记录。
- 报告数量：AI日报记录加已保存正文的研究尝试数；不同尝试分别计数。

点击用户行的“查看详情”，可只读查看该用户的详细使用情况：

- 持仓：标的、账户来源、币种、份额、平均成本、成本金额、市值、浮动盈亏和数据日期，包括现金。
- 账本：买入、卖出、定投和分红，含发生时间、份额、成交价、金额、费用、现金变动、备注和冲正状态。
- 自选标的；AI日报与股票研究报告的状态、日期和已保存正文；研究任务的阶段、尝试次数和异常原因。

本地主账本与平台账户快照分开展示，不将可能重复的快照加到主账本总额。金额按账户币种显示，数据为用户已保存的记录。浮动盈亏按“市值 − 份额 × 平均成本”计算，成本缺失显示未知，现金不计算盈亏；不包含已实现收益。列表分页每页50条。

报告按历史记录查阅，保留生成时结论，查看不触发采集、模型调用、重试或数据库写入。详情不提供修改用户数据的操作，不返回用户密码、会话信息、私有模型配置或Key。普通用户即使手工输入后台地址或调用详情接口也没有读取权限。尚未使用账户显示空记录；无法读取的数据会标为暂不可用。

## 忘记密码

管理者或服务器操作者可在本机终端执行交互重置；该命令不接受明文密码参数：

```powershell
web/backend/.venv/Scripts/python.exe -B -X utf8 web/backend/scripts/manage_users.py reset-password --data-dir data --username investor_01
```

按提示输入新密码。重置后该用户所有原有登录会话失效。重复运行初始化命令不会创建第二个管理者或覆盖已有数据归属。

## 部署和备份

本机仍默认监听127.0.0.1；所有HTTP业务入口均要求账号会话，全局Bearer Token不能绕过。开发前端通过Vite同源代理访问默认8765后端。远程部署使用HTTPS，Cookie启用Secure和HttpOnly，并进行写请求来源和CSRF校验。

Docker启动后运行交互初始化：

```sh
docker compose --env-file web/deploy/.env -f web/deploy/docker-compose.yml exec api uv run python scripts/manage_users.py init-admin
```

账号与会话位于 `data/auth/accounts.sqlite3`；普通用户数据位于 `data/users/<user-id>/`，管理员继续使用原 `data/` 根目录。备份须覆盖账号库及所有用户目录；SQLite在线备份需使用其备份API，完整目录备份应先停服务，避免遗漏WAL文件。不把data目录加入源码或公开静态目录。

原有单账户DuckDB备份命令只覆盖该账户业务事实，不能代替所有账号和用户目录的完整备份。本次没有执行公网部署。

后端运行并占用DuckDB时，命令行准入检查需要交互登录：`scripts/production_readiness.py --username 管理者用户名`；密码不作为命令参数。也可停服务后运行原离线检查。网页运行趋势和准入查询始终读取当前账号的数据。
