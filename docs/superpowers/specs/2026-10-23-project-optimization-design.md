# 已确认问题的项目优化

用户在查看剩余问题及优先级后要求“进行项目优化”。本轮落实清单中的四项确定问题，继续使用现有 Vue、.NET 和 Python 结构。

## 范围与验收

1. 问答浮窗：退出或切换账户立即清除历史、草稿和请求状态。旧会话的成功或失败响应不能进入新会话。只重新检查同一会话时保留历史。
2. 汇率：显式记录原币种与目标本币。切换本币不能沿用其他币种对的汇率；切回原本币可复用其已录入汇率。兼容已有浏览器汇率配置，异步拉取期间改变本币不能把旧结果当作新本币汇率。
3. 回测：组合回测等待上限匹配后端 600 秒任务时限，智能定投回测匹配 300 秒，均加 5 秒响应余量。其他请求维持既有 15 秒、策略配置/预览 65 秒。取消仍需及时生效。
4. 未支持问答：不再调用未注册的 ask.answer，也不读取或消耗模型预算；正常返回明确的未支持说明、可用快捷问题和 model_calls=0。现有模板查询、鉴权和账户隔离继续有效。此项不宣称接通自由大模型问答。

## 实现选择

使用现有会话事件和请求客户端完成修复。汇率按币种对保存并迁移旧格式；回测按已知端点设置等待上限，不新增任务协议。未支持问答返回明确的范围提示，避免在没有执行能力时接入付费模型。

本轮不增加数据库迁移、依赖或新模型供应商，不改写金融历史。真实 PE/PB 数据源、智能定投配置页、2FA 管理页、负债登记和汇率服务端同步仍是后续功能范围。

## 验证

先记录新增回归失败，再实现最小修复。执行前端全套单元和浏览器接口回归、真实独立 PostgreSQL 的 .NET 全套、类型/lint/格式检查及演示和连接后端构建。最终进行一次独立代码复审，再把已验证提交同步至桌面目录。原有备份分支和 stash 保留。
