# 资产统计范围与后台计算任务

基线：`6e19f8808a3c323d1f32d07c98e123a212e52ee8`。用户在阅读优化优先级后要求继续优化；本轮落实最优先的资产统计口径与长任务体验。保持 Vue / .NET / Python 架构，不增加依赖或数据库迁移。

## 目标与实现选择

- 未知币种不得当成本币计入折算；缺币种、缺汇率均明确排除并说明。折算区域统计非现金持仓，名称使用“已折算持仓市值”，避免宣称完整总资产。
- 未登记负债不展示为已确认零负债。后端增加明确范围字段，保留现有数字字段兼容旧客户端；连接模式的页面、卡片与历史曲线按持仓资产展示，净资产显示未计算。演示数据保持既有行为。
- 组合回测、估值、智能定投回测支持快速创建后台任务，取得任务 ID 后查询状态、结果或取消。现有同步接口保持兼容。
- 组合回测与估值页面显示排队、运行、完成、失败、取消、中断和可恢复的查询错误。刷新、离开再返回可恢复当前会话的任务；浏览器只保存任务 ID，不保存计算结果或输入。

考虑了仅继续放宽超时、引入新任务系统、复用 compute_jobs 三种路径。选择复用现有持久化队列、去重、期限和 Worker 租约；这是执行者的实现选择，用户未指定新技术。仅放宽超时无法恢复任务；新队列增加不必要的运维与迁移。

## 任务协议

- 既有端点增加 `background=true`：POST `/backtest/portfolio`（600 秒）、GET `/valuation`（180 秒）、POST `/dca/smart/{id}/backtest`（300 秒）。输入校验与账户所有权校验保持在入队前。
- 后台响应 202，提供 Location、Retry-After 和 `{job_id, kind, status, created_at, deadline, completed_at, result, error_code}`。有效估值缓存仍可直接返回既有 200 数据。
- GET `/compute/tasks/{id}` 返回该账户、上述三类任务的状态；DELETE 同一路径撤销队列/运行租约并返回最终状态。其他账户或其他内部任务统一 404，禁止返回输入、owner_token、Worker 标识和原始异常。
- 取消是持久化的终态；已完成任务保持结果。Worker 后续心跳和发布均被既有租约检查拒绝，子进程在下一次心跳失去所有权后关闭。外部阻塞调用不保证即时中断。
- 过期、租约失效任务以中断展示，不能无限轮询。重复相同输入沿用既有入队去重。
- 客户端存储键包含用户与会话 scope；退出、核验中、切换会话或卸载时停止本地轮询并丢弃旧回包。离开页面不自动取消后台任务。
- 查询失败允许继续查询，不重复创建任务。401/403 触发会话失效；404 说明任务不可恢复。浏览器拒绝存储时本次运行仍可用，明确提示无法自动恢复。

## 验收与边界

1. 实际 composable 和浏览器回归证明未知币种不计入折算，已知本币不要求汇率，缺汇率不会计入，未登记负债不显示成已确认零。
2. PostgreSQL 集成验证 202、验证先于入队、去重、跨账户和内部任务隔离、取消排队/运行、拒绝旧 Worker 发布、期限以及已完成结果。
3. 浏览器合成 HTTP 验证后台回测、刷新恢复、取消、查询失败后继续、会话切换迟到响应，以及估值的后台状态和原同步响应兼容。
4. 全量前端、浏览器、真实隔离 PostgreSQL .NET、lint/format/types、双构建、OpenAPI 契约和 Linux CI 通过后合并、同步桌面。保留所有原源码备份。

本轮不增加负债录入、服务端汇率同步、真实 PE/PB 数据源、智能定投管理页、模型或 SMTP 配置，也不改写账本历史、策略收益口径及生产数据库。旧数字字段仍是账本持仓口径，不是完整跨币种净资产。
