## 已完成盘点与假设

- 已检查 MarketController、FundResearchController、FundNavController、FundFeeController、FundFeeRepository、FundDetail/Response、fund_pool_commands 和 API 文档。研究、净值入账、费率及用户维护基金族均非公共分类目录；不得共享用户私有费率/份额资料。因此需要增量 `GET funds/categories`、`GET funds/catalog`，保留详情、估值、涨幅榜、关注原接口。
- 东方财富 `https://fund.eastmoney.com/js/fundcode_search.js` 实测28107条、33种原始类型、3199390字节；最小JSON结果约3976589字节，低于Worker32MiB边界。源未提供目录发布日期，source_time必须为空，不声称市场官方基金总数。公开HTTP仍有8MiB响应/并发/超时/熔断限制。
- 蛋卷023530实测身份/股票型-标准指数/投资说明/真实业绩基准可读，但 `benchmark_index` 是通用对比列表（航空基金也列沪深300等），严禁作为跟踪关系。510300蛋卷返回暂不销售，按已有fallback机制处理，不伪造。
- 新浪110020实测有明确 Type1/2/3、NewType1/2/3、tzfw、bjjz等字段。复用并保留公共资料事实；基金名不参与分类。投资范围只采用明确资料或保守可审核规则；业绩基准关联不等于跟踪；份额类别缺少直接依据则未知，不按A/C后缀猜。
- 新分类仅据供应商字段与有版本的确定规则，保留逐字段来源、原文、状态与未知；有真实资料才给市场/策略/结构/基准/份额。组合过滤在维度内OR、维度间AND，多标签可要求全部，未知可显式筛选。不把16指数、基金类别、板块目录合并。
- 目录缺NAV，按现有公共详情快照补充所选页的正式NAV/日期/已提供日涨幅，不触发每行爬虫，不给缺值补0；货币基金特殊收益口径未核验时留空。关注/自选仍在当前账户接口，不写入公共目录。
